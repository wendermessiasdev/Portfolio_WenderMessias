## Executar localmente

Sirva a pasta do projeto na raiz de um servidor local. Com Python instalado, abra um terminal nesta pasta e execute:

```bash
python -m http.server 8000
```

Depois, acesse [http://localhost:8000](http://localhost:8000) no navegador. Também é possível usar a extensão Live Server do Visual Studio Code.

> Os caminhos de CSS, JavaScript e imagens começam com `/`, então o servidor deve servir esta pasta como raiz do site.

## Estrutura

- `index.html` — conteúdo e estrutura da página.
- `css/styles.css` — variáveis, estilos globais, seções e ajustes responsivos.
- `script/` — comportamento do menu de navegação.
- `assets/` — fotos, ícones, imagens e vídeos dos projetos.
- `img/` — logotipos e favicon.
